Executive Summary

Platform overview & investment thesis
🎯

What PosturePilot Does

PosturePilot is a unified cybersecurity command center SaaS for mid-market enterprises ($50M–$2B revenue). It ingests vulnerability scan data from Qualys, Tenable, and Nessus, and provides real-time risk scoring, automated SOAR-based remediation, compliance tracking across SOC 2 / ISO 27001 / NIST / PCI-DSS / HIPAA, AI risk governance, and board-level CISO reporting — all in a single platform.

Issues Found & Fixes Applied

16 total issues · 4 critical · 8 warnings · 4 informational · 6 fixes applied

🔴 Critical / Logic Errors (4)

1
Post-Mitigation Score Overshoots to 98/95 — Higher Than Pre-Attack Baseline of 74
After triggering "Attack Wave" (score drops to 42) then running SOC Playbook, score restores to 98 (UR) or 95 (ACME) — higher than the original 74 baseline. This is physically impossible. A security incident cannot result in a better posture than before the attack. Damages credibility in investor demos.
📍 src/app/dashboard/page.tsx · Line 166 · handleTriggerMitigation()
2
Grade Logic Missing "B" Range — Score 82 Shows "C+" Instead of "B"
Grade calc: >85=A, >70=C+, else D-. No B grade exists. Score 82 shows "C+" — any enterprise buyer evaluating security software will question this immediately. A proper A/B/C/D scale is expected.
📍 src/app/dashboard/page.tsx · Line 177 · activeGrade calculation
3
Landing Page "2.4TB Today" vs Traffic Page "12.4 Gbps" — Irreconcilable Metrics
Landing page BOARDS shows Traffic Monitor val="2.4TB" unit="Today". Actual Traffic page shows 12.4 Gbps peak. 12.4 Gbps × 24h ≈ 133 TB/day — makes "2.4TB Today" impossible for the same network. One is a daily total, other is peak rate — both are presented as equivalent metrics without any context.
📍 src/app/page.tsx · Line 18 · BOARDS array, traffic entry
4
Landing Page Traffic Monitor Uses Wrong Icon (📡 instead of 🎛️)
Landing page BOARDS assigns 📡 (radar dish) to "Traffic Monitor". Traffic Control dashboard uses 🎛️ everywhere else — sidebar, layout metadata, all references. Risk Radar (📡) and Traffic Monitor (📡) both show 📡 on the landing page, creating visual collision and brand confusion.
📍 src/app/page.tsx · Line 18 · BOARDS array, icon field
